# 09 — HÌNH ẢNH / VIDEO / ÂM THANH

File trong thư mục này **không được đẩy lên GitHub** vì quá nặng (GitHub giới hạn 100MB mỗi file). Thay vào đó, mỗi lần lưu, máy tính **mã SHA-256** ("dấu vân tay") của từng file và đóng dấu thời gian. Sửa file dù chỉ một điểm ảnh thì mã sẽ khác hoàn toàn.

| Thư mục con | Để gì |
|---|---|
| `tham-khao/` | Phác thảo, ảnh tự chụp, tư liệu đầu vào **của bạn** |
| `ai-tao-ra/` | Kết quả thô AI tạo ra, đặt tên theo mã prompt (vd `C01-04.mp4`) |
| `da-chinh-sua/` | Bản bạn đã chỉnh sửa (màu, cắt, ghép…) |
| `thanh-pham/` | Bản phim hoàn chỉnh |

> ⚠️ **Hãy tự sao lưu thư mục này** (Google Drive, OneDrive, ổ cứng ngoài). Mã SHA-256 chỉ chứng minh được khi bạn **còn giữ file gốc**.
> Không sửa đè file đã lưu. Cần sửa thì lưu thành file mới (vd `C01-04_chinh-mau.mp4`).
